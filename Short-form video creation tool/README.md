# ショート動画メーカー

原稿から AI ナレーションを作り、テロップを付けて、縦長（1080×1920）の MP4 動画を書き出す個人用ツール。
手持ちの音声からテロップを付けることもできる。

## 構成

| 役割 | 中身 |
|---|---|
| 音声の生成 | Gemini API `gemini-3.8-flash-tts`（原稿全体を1回で読み上げ） |
| テロップの時刻 | Gemini API `gemini-3.5-transcribe`（単語ごとの時刻つき文字起こし） |
| テロップの文字 | 原稿の文字をそのまま使い、文字起こしと照合して時刻だけを割り当てる（原稿がないときは文字起こしの文字） |
| GAS（`Code.gs`） | API の呼び出しだけ（音声生成・文字起こし） |
| 画面（`index.html`） | テロップ分割・編集・プレビュー・動画の書き出しをすべてブラウザで処理 |
| 動画の書き出し | ブラウザの動画エンコード機能（WebCodecs）＋ mp4-muxer（CDN から読み込み） |

## セットアップ

1. **API キーを取得**：Google AI Studio で Gemini API キーを作成する（課金を設定していないプロジェクトのキーなら無料枠で動く）。
2. **新しい GAS プロジェクトを作成**：script.google.com で「新しいプロジェクト」。
3. **コードを配置**
   - `コード.gs` の中身を `Code.gs` の内容に置き換える。
   - 「ファイル ＋」→「HTML」で `index` という名前のファイルを作り、`index.html` の内容を貼り付ける。
4. **API キーを登録**：プロジェクトの設定 →「スクリプト プロパティ」に `GEMINI_API_KEY` を追加。
5. **設定確認**：エディタで `checkSetup` を実行 → ログに2つとも「OK」が出ればよい。
6. **デプロイ**：「デプロイ」→「新しいデプロイ」→ ウェブアプリ（実行：自分／アクセス：自分のみ）。
7. 表示された URL を **Chrome か Edge** で開く。

## 使い方

1. 入口を選ぶ
   - **原稿から作る**：原稿・声（30種類）・話し方の指示を入れて「音声を作る」。「声を試す」で短い文を試聴できる。
   - **手持ちの音声から作る**：音声ファイルを選ぶ。原稿があれば貼り付ける（テロップの文字に使う）。
   - **続きから編集する**：以前保存した音声と SRT / VTT を読み込む（AI は使わない）。
   - 「動画の題名」を入れると、画面上部に固定タイトルとして表示される。
2. 音声を確認して「この音声でテロップを作る」
3. 編集
   - 左の縦長プレビューで、実際の動画の見え方を確認しながら直す。赤い範囲はショート動画アプリのボタン等が重なりやすい場所（書き出す動画には入らない）。
   - **テロップ**タブ：表／テキストで編集。Enter で分割（時刻は文字起こしから計算）、行頭の Backspace で結合、Shift＋Enter でテロップ内の改行。「分け方を変えて作り直す」で1行の文字数を変えて自動分割をやり直せる。
   - **デザイン**タブ：背景色・書体、固定タイトル（大きさ・色・縁取り・帯・位置）、テロップ（大きさ・色・縁取り・帯・位置・1行の文字数）。設定はブラウザに保存される。
4. 「動画（MP4）を書き出す」→ 書き出しが終わると自動で保存される。
5. 続きを後で編集したいときは「SRT を保存」「音声を保存」で2つを保存しておく。

## 制限・注意

- 動画の書き出しは Chrome / Edge の最新版が前提。通常は映像 H.264・音声 AAC の MP4 になる。対応していない環境では VP9 / Opus になり、その旨を表示する（一部のスマホで再生できない形式）。
- mp4-muxer をインターネット（jsDelivr）から読み込むため、書き出しにはネット接続が必要。
- Gemini API の無料枠は、入力内容が Google の製品改善に使われる場合がある。業務や他人の個人情報を含む原稿・音声には使わない。
- 無料枠の回数上限は AI Studio の画面でしか確認できない。上限に達すると「利用上限」のエラーになる。
- 手持ちの音声は 20MB・30分まで。
- 編集中の内容はブラウザを閉じると消える。SRT と音声を保存しておけば「続きから編集する」で再開できる。
- アップロードした音声は文字起こし後に Gemini 側から削除する。残った場合はエディタで `cleanupFiles` を実行。

## 設定項目（スクリプトプロパティ）

| 名前 | 必須 | 内容 |
|---|---|---|
| `GEMINI_API_KEY` | ○ | Gemini API キー |
| `TTS_MODEL` | | 音声生成のモデル名（省略時 `gemini-3.8-flash-tts`。安価な `gemini-3.8-flash-lite-tts` も可） |
| `TRANSCRIBE_MODEL` | | 文字起こしのモデル名（省略時 `gemini-3.5-transcribe`） |
