# 字幕メーカー

MP3（10分程度、話者1人）から日本語字幕（SRT）を自動生成し、確認・修正して、音声と同期再生する個人用 Web アプリ。

## 構成

| 役割 | 中身 |
|---|---|
| 文字起こし | Gemini API `gemini-3.5-transcribe`（単語ごとの時刻つき・日本語指定）※無料枠で利用 |
| バックエンド | GAS（`Code.gs`）：Gemini Files API へ音声を送信 → 文字起こし → 音声を削除 |
| 画面 | GAS の HtmlService で配信（`index.html`）。外部ライブラリなし。字幕ファイルの読み込み・貼り付けにも対応 |
| 字幕への分割 | ブラウザ側で処理（句点・無音・文字数・表示時間で区切る。設定を変えて分割し直せる） |
| 再生 | 標準の `<audio>` 要素。音声はブラウザ内のファイルをそのまま再生 |

Google Drive・Cloud Speech-to-Text・サービスアカウントは使いません。

## セットアップ

1. **API キーを取得**：Google AI Studio で Gemini API キーを作成する（無料）。
2. **GAS プロジェクトを作成**：script.google.com で新しいプロジェクトを作る。
3. **コードを配置**
   - 既定の `コード.gs` の中身を `Code.gs` の内容に置き換える。
   - 「ファイル ＋」→「HTML」で `index` という名前のファイルを作り、`index.html` の内容を貼り付ける（名前は `index` のみ。`.html` は自動で付く）。
4. **API キーを登録**：左の歯車（プロジェクトの設定）→「スクリプト プロパティ」に
   - プロパティ `GEMINI_API_KEY`、値に API キー
5. **設定確認**：エディタで関数 `checkSetup` を選んで実行 → 初回は権限の承認 → ログに「OK」が出ればよい。
6. **デプロイ**：「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
7. 表示された URL を開いて利用開始（Google にログインした状態で開く）。

コードを直したときは「デプロイを管理」→ 編集 → バージョン「新バージョン」で更新する（URL は変わらない）。

## 使い方

1. MP3 をドラッグ＆ドロップ（字幕ファイルを一緒にドロップしても OK）
2. 字幕の用意のしかたを選ぶ
   - **AI で自動生成**：Gemini で文字起こし（25MB・30分まで）
   - **字幕ファイルを読み込む**：.srt / .vtt / .txt（UTF-8・Shift_JIS 対応）
   - **テキストを貼り付ける**：SRT 形式のテキストを貼り付け
3. 字幕の確認・修正
   - **表で編集**：▶ でその行だけ再生、＋ で下に追加、✕ で削除
   - **テキストで編集**：SRT のまま書き換え・丸ごと貼り替え →「反映」。番号のずれ、全角数字、「→」の矢印、```（コードブロック記号）は自動で直す。読み取れない行は行番号つきで表示
   - 「AI への依頼文をコピー」：今の字幕と依頼文をまとめてコピー。AI に原稿と一緒に渡すと、原稿の文言に合わせた SRT を作ってもらえる。返ってきたテキストを貼り付けて「反映」
   - 「全体のタイミングを ○ 秒ずらす」で一括調整（AI 生成時は分割の設定変更も可）
4. 「編集完了 → 再生へ」で同期再生（スペースキーで再生／一時停止）
5. 「SRT をダウンロード」で保存。保存できない環境では「SRT を表示（コピー用）」から手で保存

## 制限・注意

- AI で自動生成する場合のみ、ファイルサイズ 25MB まで・長さ 30 分まで（時刻つき文字起こしの上限）。字幕を読み込む・貼り付ける場合は制限なし。
- Gemini API の無料枠は、入力内容が Google の製品改善に使われる場合がある。業務や他人の個人情報を含む音声には使わない。
- 無料枠の回数上限に達すると「利用上限」のエラーになる。時間をおいて再実行。
- 単語ごとの時刻を有効にすると、文字起こし精度がやや下がる場合がある（Gemini 側の仕様）。誤字は編集画面で直す。
- アップロードした音声は文字起こし後に Gemini 側から削除する。残ってしまった場合はエディタで `cleanupFiles` を実行（いずれにせよ 48 時間で自動削除）。
- 編集中の字幕はブラウザを閉じると消える。こまめに SRT を保存する。

## 設定項目（スクリプトプロパティ）

| 名前 | 必須 | 内容 |
|---|---|---|
| `GEMINI_API_KEY` | ○ | Gemini API キー |
| `GEMINI_MODEL` | | モデル名を変えたいとき（省略時 `gemini-3.5-transcribe`） |
