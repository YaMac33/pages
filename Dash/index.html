🏛 自治体業務・案件統合管理ダッシュボード

自治体の業務・案件・会議・タスクを一元管理する、単一HTMLファイルの業務アプリです。 インストール・ビルド・サーバーは不要で、app.html をブラウザで開くだけで動作します。 データはブラウザ内（localStorage）に保存され、外部サーバーへは送信されません。

1はじめかた

起動方法

app.html をダブルクリックし、ブラウザで開くだけです。 インストール作業、ビルド、Webサーバーの用意はいずれも不要です。 

Dash/
├── app.html      ← アプリ本体（これを開く）
└── README.html   ← この説明書

動作要件

ブラウザ
Google Chrome / Microsoft Edge / Firefox / Safari の最新版
ネットワーク
初回表示時にインターネット接続が必要です。 画面部品（表・カレンダー・グラフなど）を各CDNから読み込むためです。
画面サイズ
1280×800 以上を推奨（タブレット・スマートフォンにも対応）
権限
特別な権限は不要です。ファイルの保存（出力機能）にダウンロード許可を使用します。
初回起動時の動作 保存データが無い場合、自治体業務を想定したサンプル案件24件が自動投入されます。 操作を試したあと、［データ入出力］タブの「全データをリセット」で消去し、実データの登録を始めてください。 サンプルは起動日を基準に日付が生成されるため、いつ開いても直近の案件として表示されます。
庁内ネットワークでご利用の場合 プロキシやフィルタリングで外部接続が制限されていると、一部の画面部品を読み込めないことがあります。 その場合は画面上部に警告が表示され、［設定］タブの「ライブラリ稼働状況」で どの機能が利用できないかを確認できます。読み込めなかった機能のボタンは自動的に無効化され、 アプリ全体が停止することはありません。

2画面構成

左サイドバーで8つの画面を切り替えます。括弧内はショートカットキーです。

📊 ダッシュボード 1

KPIカード8種、全体進捗、グラフ4種（ステータス別・部署別・月別推移・優先度別）、 締切が近い案件、直近の会議予定を一覧表示。KPIカードをクリックすると、その条件で案件一覧を絞り込みます。 PDF出力・印刷もこの画面から行います。

📋 案件一覧 2

並び替え・列見出しでの絞り込み・セルのインライン編集・ページ送り・行選択に対応した一覧表。 選択行に対して詳細表示／編集／複製／ステータス一括変更／印刷／削除が行えます。 表示する列は自由に切り替えられ、設定は保存されます。

📅 カレンダー 3

月・週・一覧の3表示。案件の実施期間、会議予定、締切日を表示します。 空き日付をクリックすると、その日を開始日とした新規登録画面が開きます。 予定をクリックすると案件詳細が開きます。

📈 タイムライン 4

案件の開始日〜終了日をガント風に表示。担当部署・ステータス・優先度・担当者でグループ化できます。 バーをドラッグして日程を直接変更でき（要許可設定）、変更内容はそのまま保存されます。

🔎 全文検索 5

案件名・部署・担当者・説明文・タグ・取込文書本文を横断検索します。 日本語のあいまい検索に対応し、一致箇所をハイライト表示。 検索結果はJSON／CSVで保存でき、一覧タブの絞り込み条件へ引き継げます。

🔁 データ入出力 6

CSV・Excel・JSONの取込と書き出し。ファイルはドラッグ＆ドロップでも取り込めます。 取込前に内容をプレビューし、「既存に追加」か「すべて置き換え」を選べます。 サンプルデータの再生成、全データのリセットもここから行います。

📃 文書確認 7

Word文書（.docx）を取り込み、本文を抽出してプレビューします。 抽出した本文から新規案件を起票したり、既存案件の文書欄へ反映できます。 反映した本文は全文検索の対象になります。

⚙ 設定 8

操作ログの確認とCSV保存、表示テーマの切替、キーボード操作の一覧、 ライブラリ稼働状況、保存容量などのアプリ情報を確認できます。

3主な機能

すべての画面が同じデータに連動します

案件の追加・編集・削除・取込を行うと、グラフ・一覧・カレンダー・タイムライン・検索索引のすべてが即座に更新され、 同時にブラウザへ保存されます。どの画面から操作しても内容がずれることはありません。

一覧タブの「フィルタをダッシュボード・カレンダー・タイムライン・検索にも適用する」を有効にすると、 絞り込み条件が全画面に反映され、特定部署だけの集計や印刷が行えます（初期値は有効）。

登録・編集

  • 新規登録／編集フォーム（必須チェック、終了日が開始日より前でないかの検証つき）
  • 一覧表のセルをダブルクリックしてのインライン編集（不正な値は自動的に元へ戻ります）
  • 案件の複製（「（複製）」を付けて未着手で起票）
  • 選択した複数案件のステータス一括変更
  • タイムラインのバーをドラッグしての日程変更

取り消し（元に戻す）

追加・削除・取込・リセットなどの操作は最大10世代まで取り消せます。 一覧タブの「元に戻す」ボタン、または Ctrl + Z で直前の操作を取り消してください。

誤って全削除したときも復旧できます 「全データをリセット」の直後であれば、Ctrl + Z で元に戻せます。 ただし取り消し履歴はページを再読み込みすると消えるため、 重要なデータはJSON出力による定期的なバックアップを推奨します（Ctrl + S）。

集計と可視化

  • KPIカード：対象案件数／未着手／進行中／保留／完了／期限超過／7日以内締切／今後の会議
  • 円グラフ：ステータス別件数（中央に合計）
  • 棒グラフ：部署別件数（上位10部署・ステータス積み上げ）
  • 折れ線グラフ：月別の案件開始件数と会議予定件数の推移
  • 横棒グラフ：優先度別件数（ステータス内訳）

締切管理

終了日をもとに残日数を自動計算し、期限超過・ 本日締切・ 7日以内を色分けして表示します。 一覧表では期限超過の行に赤い縦線、タイムラインでは赤枠が付きます。完了案件は対象外です。

取込のはじめかた

  1. ［データ入出力］タブの「取込用テンプレートCSVを保存」で、正しい列構成のひな形を入手します。
  2. ひな形に案件を記入します（id は空欄のままで構いません。自動採番されます）。
  3. CSVを取り込み、プレビューで内容を確認します。
  4. 「既存に追加する」（既存データを残して追加。同じIDは上書き更新）または 「すべて置き換える」（既存データを破棄）を選びます。

7データの保存先

入力したデータは、お使いのブラウザ内の localStorage に自動保存されます。 外部サーバーへ送信されることはありません。 画面右上の「保存済み ○○:○○:○○」表示で、最後に保存された時刻を確認できます。

保存キー内容
muni_pms_records_v2案件データ本体
muni_pms_logs_v2操作ログ（最新200件）
muni_pms_theme_v2表示テーマ（ライト／ダーク）
muni_pms_prefs_v2表示列、フィルタ連動、タイムラインのグループ化などの画面設定
データが消える場合があります
  • ブラウザの「閲覧履歴／サイトデータの削除」を実行したとき
  • シークレットウィンドウ（プライベートブラウジング）で使用したとき
  • 別のパソコン、別のブラウザ、別のユーザープロファイルで開いたとき
    → データはブラウザごとに保存されるため、他の端末とは共有されません。

重要なデータは必ず「JSON出力」でバックアップしてください。 出力したJSONファイルを取り込めば、別の端末でも同じ状態を復元でき、共有手段としても使えます。

保存容量の上限はブラウザ全体で概ね5MB程度です。現在の使用量は［設定］タブの「保存容量」で確認できます。 通常の運用（数千件程度）で上限に達することはほとんどありませんが、 文書本文を大量に取り込む場合はご注意ください。

9カスタマイズ

app.html をテキストエディタで開いて編集します。 JavaScriptは末尾の <script> 内にまとまっており、 0. 〜 4. の番号付きコメントで区切られています。

ステータス・優先度を変更する

「1. 定数定義」の以下を書き換えます。STATUS_META の色分けもあわせて更新してください。

var STATUS_OPTIONS   = ['未着手', '進行中', '保留', '完了'];
var PRIORITY_OPTIONS = ['高', '中', '低'];

var STATUS_META = {
  '未着手': { color: '#8fa2b0', cls: 'st0', order: 0 },
  '進行中': { color: '#1c66b8', cls: 'st1', order: 1 },
  '保留':   { color: '#b5710a', cls: 'st2', order: 2 },
  '完了':   { color: '#1b7f3b', cls: 'st3', order: 3 }
};

バッジの表示色はCSS側の .st-未着手 / .pr-高 のような 「クラス名に日本語をそのまま使った定義」で指定しています。項目名を変えた場合は、 CSSのクラス名（ライト・ダーク両方）もあわせて追加してください。

サンプルデータを差し替える

「3. サンプルデータ生成」の SAMPLE_SEEDS を編集します。 s は本日からの開始日オフセット（日数）、d は期間の長さ、 mt は会議予定の有無と時期を表します。相対指定のため、いつ開いても直近の日付になります。 

{ title: '令和8年度当初予算編成', dept: '財政課', cat: '予算',
  tags: '予算,重要,全庁', desc: '……',
  s: -42,        // 開始日 ＝ 本日の42日前
  d: 120,        // 期間   ＝ 120日間
  st: '進行中',  // ステータス
  pr: '高',      // 優先度
  mt: 3 }        // 会議あり（0 なら会議なし）

配色を変える

<style> 先頭の「1. デザイントークン」にあるCSS変数を書き換えます。 :root がライトモード、:root[data-theme="dark"] がダークモードです。 アクセントカラーは --accent と --accent-2 の2つで決まります。

10設計メモ

改修時に壊しやすい箇所です。変更前にご一読ください。

データ更新は必ず commit() を通す

案件データ records が唯一のデータ源です。更新後に commit() を呼ぶと、 保存 → 検索索引の再構築 → 集計の再計算 → 全画面の再描画が この順で一括実行されます。個別に描画関数を呼ぶと画面間で内容がずれるため、必ず commit() を経由してください。 

this.pushHistory('操作名');        // 取り消し用のスナップショットを保存
this.records[i].status = '完了';   // データを変更
this.commit('ログに残す文言', 'edit');

ライブラリのインスタンスは Alpine の管理下に置かない

表・カレンダー・グラフなどのインスタンスは、コンポーネント内の view という クロージャ変数に保持しています。Alpineのリアクティブプロキシに載せると、 巨大なライブラリ内部までプロキシ化されて動作不良や速度低下を招くためです。 this._table = ... のようにコンポーネントのプロパティへ保持しないでください。

再描画は「破棄→再生成」ではなく差分更新

カレンダーはイベントのみ差し替え、タイムラインはデータセットの中身のみ入れ替えています。 毎回作り直すと、表示中の月やズーム位置が編集のたびに初期化されてしまうためです。 グループ構成が変わる場合のみ renderTimeline(true) で作り直します。

既知の落とし穴（対策済み・再発注意）
  • 一覧表は非表示のまま生成しない。高さ0の要素で初期化すると内部の描画機構が構築されず、 タブ表示時の再描画で例外が発生します。［案件一覧］タブを開いた時点で生成し、 tableBuilt の完了を待ってから操作しています。
  • 印刷対象を display:none にしない。Print.js は対象要素の計算済みスタイルごと複製するため、 非表示だと印刷結果が空になります。#printHolder は画面外へ逃がす方式にしています。
  • PDF出力には静的な複製を渡す。html2pdf は対象要素の複製を実DOMへ一時挿入するため、 Alpineの属性が残っていると「x-data の外にある要素」として初期化が試みられ、大量のエラーが発生します。 buildDashboardSnapshot() でAlpine属性を除去し x-ignore を付与しています。 あわせて、複製ではグラフの描画内容が失われるため、キャンバスは画像へ置換しています。
  • ダイアログの重なり順。SweetAlert2 の既定の重ね順は独自モーダルより低いため、 CSSで .swal2-container を引き上げています。
  • テーマは <html> に付与する。ダイアログは <body> 直下に生成されるため、 アプリ内側の要素に付けるとダーク配色が適用されません。

日本語の全文検索

MiniSearch の標準の単語分割は空白区切りを前提としており、日本語では機能しません。 そのため buildSearchIndex() で独自の分割処理を実装し、 2文字組（バイグラム）を併せて索引することで「防災」「予算」などの部分一致を可能にしています。 検索候補の提示では、断片的な2文字の候補を除外しています。

カレンダー月表示の表現

数か月にわたる案件バーをそのまま月表示に並べると全週を占有し、会議や締切が「+N件」に隠れてしまいます。 そのため月表示では期間を背景の色帯（重なるほど濃くなり繁忙期が分かる）として描き、 開始日にクリック可能な見出しを1つ置いています。週・一覧表示では従来どおり期間バーで表示します。 表示切替は datesSet で検知して再構築しています。

11制約と注意事項

  • インターネット接続が必要です。画面部品をCDNから読み込むため、完全オフラインでは動作しません。
  • データは端末内のブラウザにのみ保存されます。複数人での同時編集や自動共有はできません。 共有する場合はJSON出力ファイルを受け渡してください。
  • 取り消し履歴はページを閉じると消えます。最大10世代・そのセッション中のみ有効です。
  • Excelの取込は先頭シートのみが対象です。
  • Word文書は .docx のみ対応です。旧形式の .doc は変換できません。 画像を含む文書では、画像はプレビューに表示されないことがあります。
  • PDF出力は画面を画像として描画するため、案件数が多いと時間がかかり、文字の選択・検索はできません。
  • 認証・権限管理の機能はありません。端末の管理は運用でご対応ください。
  • 個人情報を扱う場合は、所属団体の情報セキュリティポリシーに従ってご利用ください。

12困ったときは

症状確認すること
画面が真っ白のまま表示されない インターネットに接続されているか確認してください。社内プロキシで cdn.jsdelivr.net / cdnjs.cloudflare.com / unpkg.com / cdn.sheetjs.com への接続が 許可されている必要があります。
上部に「一部のライブラリを読み込めませんでした」と表示される ［設定］タブの「ライブラリ稼働状況」で、読み込めなかったものを確認してください。 該当機能のボタンは無効化されますが、他の機能は通常どおり使用できます。 ページの再読み込みで解消することがあります。
登録したデータが消えた 別のブラウザ・別の端末・シークレットウィンドウで開いていないかご確認ください。 データはブラウザごとに保存されます。閲覧履歴の削除でも消去されます。
Excelで開いたCSVが文字化けする 本アプリのCSVはBOM付きUTF-8で出力しており、通常は文字化けしません。 古いExcelをお使いの場合は、Excelの「データ」→「テキストまたはCSVから」で 文字コードにUTF-8を指定して開いてください。
CSVを取り込むと文字化けする／列を認識しない ［データ入出力］タブの「CSVの文字コード」を切り替えてください。 Excelで作成した従来形式のCSVは Shift_JIS です。 また、案件名（title）の列が存在するかご確認ください。
「保存エラー」と表示される ブラウザの保存容量が上限に達している可能性があります。 JSON出力でバックアップを取ったうえで、不要な案件の削除、 または文書本文（docText）の整理をご検討ください。
PDFのグラフや文字が欠ける ブラウザの表示倍率を100%に戻してからお試しください。 案件数が多い場合は、フィルタで対象を絞ってから出力すると安定します。
印刷プレビューに何も表示されない ポップアップブロックを解除してください。印刷は一時的な別ウィンドウを使用します。
操作を間違えた／消してしまった Ctrl + Z、または一覧タブの「元に戻す」で復旧できます （ページを再読み込みする前に限ります）。
初期状態に戻したい ［データ入出力］タブの「全データをリセット」、 または「サンプルデータを再生成」を実行してください。
